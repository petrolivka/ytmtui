# Code of conduct

## The short version

Be decent. Assume the other person is trying to help.

## The slightly longer version

This project welcomes contributions and questions from anyone. Harassment,
personal attacks, demeaning comments, and unwelcome attention are not
acceptable, in issues, pull requests, commit messages, or anywhere else the
project is discussed.

Technical disagreement is fine and useful. Make it about the work: what the code
does, what it costs, what evidence supports it. "This is wrong because X breaks
when Y" is a contribution. "You clearly have no idea what you are doing" is not.

If someone tells you their pronouns, use them. If you do not know, they/them
works.

## If something goes wrong

Report it to the maintainers privately by opening a GitHub security advisory or
emailing the address in the package metadata. Reports are handled discreetly.
Maintainers may edit, remove, or reject contributions that breach this document,
and may block persistent offenders.

## Attribution

This is a deliberately short policy in the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org). If you need the
full formal text for a legal or organisational reason, treat Contributor
Covenant 2.1 as the fallback.
